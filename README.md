# AWS AI Practitioner Cheatsheet

A free one-page cheatsheet and flashcard deck for the AWS Certified AI Practitioner exam (AIF-C01).

**Live site:** https://sudiptobaral.com/ai-practitioner-cheatsheet/

## What is inside

- `index.html` - the cheatsheet: every service, Bedrock, ML concepts, responsible AI, security, a scenario-to-service picker, and the traps that repeat, organized by exam domain and color coded.
- `flashcards.html` - 80+ flashcards built from the same content, with domain filters, shuffle, keyboard shortcuts, and progress saved in your browser.

## Running locally

It is a static site with no build step.
Open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
